🧜‍♀️ The Jal Pari Language

A small, safe, fast programming language — dedicated to Teju, the Jal Pari. No null, no implicit conversions, checked arithmetic in safe mode, and a real machine-learning stack: tensors, autograd, transformers, GPU kernels.

Try it

git clone https://github.com/jayantt1dubeyy/RED-MOON-
cd RED-MOON-
./scripts/install.sh
jalpari run examples/jal_pari_demo.fg

Or try the browser playground (live editor — real compiler + WebAssembly in your browser, no install).

Verified numbers (measured 26 Oct 2026, not projections)

  • Version 1.0.0 (market-ready): stability promise, live browser playground, HTTP server, regex engine, seven registry packages, packaged VS Code extension, benchmarks vs Python/Go/Rust/C.
  • TinyStories word GPT, 49,664 params: held-out perplexity 1119 → 189.
  • Bigger TinyStories run, 153,744 params: held-out perplexity 2129 → 651 — better, still not fluent.
  • Tensor autograd: one forward is 136 tape nodes, where the scalar tape needed 221,844.
  • Training step: 26 ms at the scaled size, 4.35 ms at the small size.
  • dot(5000): 8 µs (NumPy 29 µs, pure Python 788 µs, same machine).
  • matmul 64×64: 615 µs (NumPy 343 µs with BLAS, pure Python 476,501 µs).
  • GPU kernels: verified on Kaggle Tesla T4 — dot 70, matmul 19 22 43 50, attention exact to 6 decimals.
  • GPU training: verified on Tesla T4 — XOR MLP learns (loss 0.001529, predictions ~0, 1, 1, 0).
  • big32 soft-float: 60/60 randomized cases vs Python float32, model and Verilog.

Honest limits

  • Generation is word salad, not fluent prose — perplexity is the solid result.
  • NumPy still wins matmul (BLAS).
  • CI, repo rename, and the public registry host need the maintainer's own clicks/accounts.
