Dedicated to Teju — Jal Pari. These programs were compiled with the Jal Pari WASM backend (forge.py emit-wasm) and run in your browser, no server, no install. WASM functions here return a number; there is no print in WASM yet, so the result is shown below.

Click a program to run it.

To compile your own program: python3 forge.py emit-wasm yourfile.fg -o out.wasm, then load it in a page like this one and call instance.exports.main(). WASM v2 supports int, float, bool — strings and arrays are not yet supported there, honestly.
