What works here, honestly

  • Full Jal Pari programs that fit the WASM subset: int, float, bool, str, flat arrays, functions, if/while/for, print/println of str/int/bool. The compiler's own errors are shown verbatim when code doesn't fit.
  • import works only for stdlib files that fit the subset too (rand.fg, dates.fg verified). Files using split, structs, enums, or float printing fail the whole program — the WASM backend compiles every imported function, used or not. That limitation is in the backend, not this page.
  • Output lives in an 8192-byte buffer: longer output is truncated, by design.
  • There is no free/GC in the WASM backend: allocations inside a loop grow memory.
  • The compiler is fetched from the repo's main branch via jsDelivr, so it may lag the newest push by a few minutes. The page itself needs internet for the first load; after that, runs are fully local.
